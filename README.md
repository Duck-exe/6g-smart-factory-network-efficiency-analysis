# Impact of 6G Network Performance on Manufacturing Efficiency in Smart Factories

This project analyzes how 6G network latency and packet loss impact manufacturing efficiency, production speed, defect rates, and operational reliability in Industry 4.0 smart factories.

## Features

- Network Performance Profiling
- Latency Impact Analysis
- Packet Loss Diagnostics
- Manufacturing Efficiency Analysis
- KPI Dashboard
- 6G Optimization Insights

## Technologies

- Python
- Pandas
- Plotly
- Streamlit

## Dataset

Manufacturing operational data with network latency, packet loss, production speed, defect rate, error rate, and efficiency status metrics.
